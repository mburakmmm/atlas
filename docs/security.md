# Security Considerations

## 1. CSV Formula Injection Protection
When CSV files generated by an application are downloaded and opened in desktop spreadsheet software (Excel, Calc), cells starting with `=`, `+`, `-`, or `@` can be treated as executable formula macros.
Atlas provides `safe_spreadsheet=True` in `to_csv()` and `write_csv_file()` which safely prepends `'` (apostrophe) to neutralize formula evaluation.

## 2. Path Traversal & Unsafe Overwrite Prevention
Nox `nox.fs` does not automatically sandbox paths. Atlas prevents silent data loss by verifying path existence before writing:
- `write_csv_file()` and `write_json_file()` check `nox.fs.exists(path)`.
- If the file exists and `overwrite=False` (the default), an `AtlasError` is raised immediately.

## 3. No Arbitrary Code Evaluation
Filter expressions and query operations in Atlas are strictly declarative AST nodes (`Expr`). Atlas contains no `eval()`, string interpolation into code, or dynamic interpreter logic.
