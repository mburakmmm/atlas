# Compatibility & System Requirements

## 1. Compiler & Platform Requirements

- **Nox Compiler**: `noxc >= 2.0.0` (verified on `noxc 2.0.86`).
- **Operating Systems**: macOS (Darwin x86_64 / arm64), Linux (x86_64 / aarch64), Windows.
- **Backend**: LLVM and QBE backends.
- **Profiles**: Hosted profile (relies on `nox.csv`, `nox.json`, `nox.mathx`, `nox.fs`).

## 2. Dependencies

Atlas has **zero external third-party dependencies**. It relies entirely on the verified Nox standard library.
